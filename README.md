# 📄 Resume Builder

A simple and responsive Resume Builder web application built using HTML, CSS, and JavaScript.

## 🚀 Features

- 👤 Personal Information
- 📝 Professional Summary
- 🎓 Education
- 💡 Skills
- 🚀 Projects
- 💼 Experience / Internship
- 🏆 Certifications
- 👀 Live Resume Preview
- ➕ Add and Remove Multiple Entries
- 💾 Automatic Data Saving using LocalStorage
- 📄 Download Resume as PDF
- 📱 Responsive Design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- html2pdf.js

▶️ How to Run
Download or clone this repository.
Open the project folder.
Open index.html in a web browser.
Enter your resume information.
Check the live preview.
Click Download Resume to download your resume as a PDF.
